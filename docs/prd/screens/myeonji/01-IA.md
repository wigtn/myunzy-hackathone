# 01 · Information Architecture — 면지 (面zy)

> **Source**: docs/prd/PRD_myeonji.md (§5.4, §3)
> **Style**: Command Center (Dark Technical)
> **Scope**: 데모 4페이지 (`/history`는 Phase 3 → 제외)

## Site Map

```
면지 (guest 단독 동작 — 로그인 없음)
│
├─ /                        랜딩 · 시나리오 소개 · 시작 CTA
│
├─ /setup                   이력서 업로드 + 회사/직무 입력
│                           → POST /sessions (OCR→수집→갭→페르소나)
│                           → 작업 로그 라이브 + 부트스트랩 진행
│
├─ /spar/[sessionId]        면접 진행 (음성/텍스트)
│                           → POST /sessions/{id}/turns (라이브 툴콜)
│                           → 합격확률 게이지 · 에이전트 작업 로그 · 자가진화 diff
│                           → 라운드 종료 → POST /sessions/{id}/verdict
│
└─ /result/[sessionId]      판정 카드 · Fit Gap 리포트 · 분기 리플레이
                            → POST /sessions/{id}/replay
                            → "다시하기" → /spar  |  "처음으로" → /

[Phase 3] /history          author 전용 성장 추적 (이번 데모 제외)
```

## Page ↔ FR ↔ API 매핑

| Route | Audience | Auth | Linked FR | 주요 API |
|-------|----------|------|-----------|----------|
| `/` | guest, author | Optional | FR-001 | — |
| `/setup` | guest, author | Optional | FR-001~005, FR-022(동의) | `POST /sessions` |
| `/spar/[id]` | guest, author | Optional | FR-006~012, 015, 017 | `POST /sessions/{id}/turns`, `verdict` |
| `/result/[id]` | guest, author | Optional | FR-014, 016, 018 | `POST /sessions/{id}/verdict`, `replay` |

## Global Components (전 페이지 공유)

| 컴포넌트 | 설명 | 등장 페이지 |
|----------|------|------------|
| `AppShell` | 다크 테마 셸, 상단 미니 헤더(로고 `면지` + 세션 상태 dot) | 전체 |
| `AgentLogPanel` | ▸ 에이전트 작업 로그 피드 (터미널 스타일, step·status·`[mock]` 배지) | /setup, /spar |
| `ToastErr` | 업스트림 장애/STT 실패 시 인라인 토스트 + 폴백 CTA | /setup, /spar |
| `MockBadge` | mock 소스 표시 배지 (정직성) | /spar, /result |

## Navigation Model

- **선형 퍼널**: `/` → `/setup` → `/spar` → `/result`. 뒤로가기 최소화(세션 상태 휘발).
- **루프백**: `/result`에서 `/spar`(다시하기) 또는 `/`(처음으로).
- **딥링크**: `/spar/[id]`, `/result/[id]`는 sessionId 유효성 검사 → 무효 시 `/`로 리다이렉트 + 토스트.
- **글로벌 nav 없음**: 데모 몰입을 위해 퍼널 외 이동 경로 숨김.

## Content Priority (페이지별 시선 우선순위)

| Route | 1순위 | 2순위 | 3순위 |
|-------|-------|-------|-------|
| `/` | 시작 CTA | 1줄 가치 제안 | 동작 원리 3스텝 |
| `/setup` | 이력서 드롭존 | 회사/직무 입력 | 작업 로그(생성 중) |
| `/spar` | 면접관 말풍선 + 입력 | 합격확률 게이지 | 에이전트 작업 로그 |
| `/result` | 다차원 점수 카드 | 분기 리플레이 | Fit Gap 리포트 |
